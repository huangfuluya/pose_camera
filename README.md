# PoseCamera

一款适用于 Android 平台的辅助拍照应用，核心功能包括：

- **参考图片叠加**：拍照时选择一张参考图片，该图片以半透明形式在相机预览中缓慢淡入淡出，便于对照构图。
- **自动修图**：拍照完成后，可自动将所拍照片的色调、亮度、对比度等风格调整为与参考图片近似，并支持手动调节融合强度。

---

## 功能说明

### 1. 选择参考图片（MainActivity）
- 从相册中选择一张参考图片。
- 选好后点击"打开相机"进入拍摄界面。

### 2. 相机拍摄（CameraActivity）
- 相机实时预览画面上叠加参考图片，自动播放淡入淡出动画。
- 可通过顶部滑动条调整参考图片的最大透明度。
- 可暂停/恢复动画。
- 支持前后摄像头切换。
- 点击快门拍照，拍摄完成后进入修图界面。

### 3. 自动修图（PhotoEditActivity）
- 显示刚拍摄的照片与参考图缩略图。
- 点击"应用风格"，系统通过**颜色统计迁移算法**自动调整照片的 RGB 均值和标准差，使其与参考图风格匹配。
- 底部滑动条可在原图和风格化结果之间任意融合。
- 点击"保存照片"将结果保存至相册。

## 技术栈

| 技术 | 用途 |
|------|------|
| Kotlin | 应用开发语言 |
| CameraX | 相机预览与拍照 |
| ObjectAnimator | 参考图片淡入淡出动画 |
| ColorMatrix | 颜色风格迁移 |
| Coroutines | 后台图像处理 |
| ViewBinding | 视图绑定 |

---

## 构建方式

1. 使用 Android Studio（Hedgehog 或更新版本）打开项目。
2. 连接 Android 设备（API 24+）或启动模拟器。
3. 点击 **Run** 即可构建并安装。

> 所需权限：相机权限、相册读取权限（Android 13+ 使用 `READ_MEDIA_IMAGES`）。
